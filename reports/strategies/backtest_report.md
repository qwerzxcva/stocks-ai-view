# 10 策略全历史回测报告 — 无前视 asof 修正版

- 模式：full；标的池 50 只主板蓝筹/龙头；评估窗口 ~490 交易日（近 2 年，数据至 2026-10-23）
- 口径：T 日收盘买入 → T+5/T+10 收盘计收益，信号仅用 T 日及之前数据；基准 = 同期沪深300（sh000300）日期对齐
- 超额 pp = 策略平均收益 − 同期基准平均收益（百分点）；CI = Wilson 95%（对胜率）

## 无前视管线（与前版的关键差异）

每个回测时点 t：
1. `kline = slice_asof(kline, t)`：截到 t 当日（含），绝不传 t 之后 bar；
2. `context = load_context(asof=t)`：market_score 按 asof 由 sh000001 历史重算（MA20/60 位置+20日动量，0-100），dt_count 按 asof 由 bulk 主分片全市场统计主板跌幅≤-9.8%家数；无历史序列的快照源（ban_prob/limitup_ml/moneyflow/lhb/market_anomaly）降级为 None，绝不拿当前快照冒充历史；
3. `regime_t = regime_router.judge_regime(bars[:i+1])` 逐日无前视判定，注入 `context['regime']` 后传入 evaluate（_context 在 asof 模式下 regime 置 None，职责分离）。

无前视生效验证（`bt_driver.py --verify`）：同一指数序列不同时点 asof 的 market_score 分别为 57.5 / 62.12 / 31.59 / 29.41（随时间变化），context.regime=None 且 `_nolookahead=True` → PASS。

## 诚实性标注（重要）

1. 依赖无历史序列快照源的策略在无前视模式下被诚实降级：**S10 主力资金**（moneyflow=None）n=0；**S07 情绪打板**（连板/情绪梯队快照）n=20；**S02 保守风控** n=80、**S04 盘中突破** n=39（日内快照降级）。**这是数据源无历史序列的诚实降级，不是策略失效**；对应行已如实列出，不做填补。
2. 未扣交易成本/滑点；主板蓝筹池存在幸存者偏差（池为当前龙头）。
3. 最大回撤为「信号序列按时间序累计净值」口径，非组合净值口径。
4. 负 edge 如实保留，不做挑选展示。
