# Phase 3 · 周期网格多参数稳健性检验（100 点网格假设）

- 引擎：`scripts/engines/cycle_grid_tester.py`
- 数据：上证综指 sh000001 全本地历史 2023-06-16 ~ 2026-10-09（801 交易日，约 3.3 年）
- 检验：分形顶/谷落在「N 点整数网格 ±band 带」内的比例 vs 随机水平；二项精确检验 + Monte Carlo（1000 次随机平移网格，seed=42）
- 参数扫描：grid ∈ {50, 100, 200}，band ∈ {20, 30, 50}，window ∈ {3, 5, 8}，共 27 组合

- **27 组合中无任何一组 p < 0.05**；最显著为 grid=200/band=30/window=8 的 MC p=0.068，仍未达显著，且方向偏离零假设的样本只有 59 个枢轴点，功效不足。

## 结论：「100 点网格」对参数不稳健地成立 → 不成立

- 100 点网格 + 常用 band/window 下，命中率与随机期望几乎重合（如 0.414 vs 0.400、0.598 vs 0.600）。
- 观察到的微小超额（如 w=8 时 0.678 vs 0.600）在样本量 59 下远不显著，且随 window 参数变化而消失，是典型的**参数敏感噪声**。
- 统计上不能拒绝「分形顶/谷在百点网格的聚集与随机无异」。网格说法**无统计支持**。
