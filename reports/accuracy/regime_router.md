# regime_router 准确度摘要

数据源：`reports/accuracy/regime_router.json`（sh000001，811 根，评估窗 2023-09-12 ~ 2026-09-17，T+20 前瞻验证）

- 口径：判定正确 = bull 后 T+20 涨 / bear 后 T+20 跌 / range 后 T+20 震荡（|fwd|<3%）；无条件三分类随机基线 51.3%。
- 样本分布（default 档）：bull 403 / bear 157 / range 171，n=731。

| 档位 | n | 准确率 | Wilson 95% CI |
|---|---|---|---|
| default | 731 | 51.7% | [48.1%, 55.3%] |
| conservative | 731 | 50.8% | [47.1%, 54.4%] |
| aggressive | 731 | **54.6%** | [51.0%, 58.2%] |

- 分年 n：2023=73 / 2024=242 / 2025=243 / 2026=173。
- 结论：三档准确率均仅与随机基线（51.3%）持平，CI 全部覆盖基线 → **regime 判定无统计显著的方向预测力**；aggressive 档相对最优。regime 标签可作分层统计维度使用，但不宜作为加权/开关的强信号。
