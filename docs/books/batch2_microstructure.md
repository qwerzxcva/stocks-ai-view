## 订单流交易（Order Flow Trading）

**核心命题**：价格不是"买卖双方同意"的结果，而是**主动单吃掉被动单**的痕迹。同一根 K 线内部，
谁在主动（aggressor）、在哪个价位、吃了多少，才是信息本体；OHLC 只是这些微观事件被压缩后的残渣。
因此它主张：用足迹图（footprint）把"每个价位的买卖主动量"展开，用 delta（主动买−主动卖）判断方向意图，
用吸收（absorption）识别大额被动单把主动流"吞掉却不前进"，用失衡（imbalance）标记薄档位。
**它和批次一所有书的根本分歧**：批次一用同一组 OHLCV 描述结果，订单流认为结果与原因不在同一粒度上。

### 可判定判据表 A：真订单流（**全部需要逐笔或分钟数据，当前不可落地**）

| 判据 | 计算定义（含阈值/单位） | 方向 | 置信度 |
|---|---|---|---|
| delta（单根） | Σ主动买量 − Σ主动卖量，单位：手/股，按 bar 聚合 | delta>0 且价涨=同向确认；delta 与价背离=吸收或衰竭 | 高（定义确定）／数据不可得 |
| CVD（累计 delta） | 全样本 delta 累加；取近 20 根线性斜率 | 价格新高而 CVD 不新高=顶部吸收，反向亦然 | 高／数据不可得 |
| 对角失衡 | 同价位卖量 ×3 ≤ 相邻价位买量（300%，亦有 400% 口径，需按品种校准） | 连续失衡价位带构成支撑/阻力 | 中／数据不可得 |
| 堆叠失衡（stacked） | 连续 ≥3 个价位同向失衡 | 方向性启动的强证据 | 中／数据不可得 |
| 吸收（absorption） | 某价位累计成交量 ≥ 近 20 根平均单档量 ×3，且该价位反复成交但价格位移 < 1 tick | 卖压被吃光=蓄势向上；镜像为派发 | 中／数据不可得 |
| 冰山单（iceberg） | 同一价位显示量被吃穿后立即回填等量 ≥5 次 | 隐藏大单=该价位是真实边界 | 低（记忆模糊）／数据不可得 |
| 成交量分布 POC/VA | 按价格分桶累加成交量；POC=峰桶；价值区=覆盖 70% 成交量的价格区间 | 价格跑出 VA 上沿=过度延伸，回归 VA 概率上升 | 高（定义）／数据不可得 |
| 单边高潮（exhaustion） | 单根总量 ≥ 20 根均值 ×3，delta 极高后下一根 delta 反向 | 短线反转 | 中／数据不可得 |
| VWAP 偏离 | (C − VWAP)/σ_vwap | 偏离 >2σ 且 delta 衰减=均值回归 | 中／数据不可得 |

### 可判定判据表 B：日线代理（**可落地，但只是代理，不是订单流**）

| 判据 | 计算定义（含阈值/单位） | 方向 | 置信度 |
|---|---|---|---|
| 收盘位置 CLV | (C−L)/(H−L)，无量纲 0~1；H==L 时须特判（一字板） | >0.7 多头掌控当日；<0.3 空头掌控 | 中（方向代理） |
| CLV 均值 | 近 5 日 CLV 均值 | 连续 >0.6=买盘持续性 | 中 |
| 量比 | V_t / mean(V,20)；无量纲 | >1.5 放量；>2.5 异动；**无方向** | 高（定义）／中（阈值） |
| 振幅归一化 | amp = (H−L)/close；amp_atr = (H−L)/ATR14 | amp_atr >1.5=分歧大（**不等于**流动性薄） | 中 |
| 缺口 | (open_t − close_{t−1}) / ATR14 | 向上缺口未回补=竞价失衡仍在 | 中 |
| 上/下影占比 | lower_wick/(H−L)、upper_wick/(H−L) | 长下影=下方有被动买盘（**吸收嫌疑**，不是证明） | 中 |
| 近似成交量分布 | 每根 bar 的 V 按典型价 (H+L+C)/3 落入价格桶（桶宽 0.5×ATR）累加 | 峰桶≈日线 POC 近似 | **低（失真大）** |
| 吸收嫌疑合成 | vol_ratio>1.8 且 \|涨跌幅\|<0.5% 且 amp_atr<1.2 | 疑似吸收，**方向标 unknown** | 中 |

**代理丢掉了什么（必须写清楚）**：① **方向**——日线只有总量，拿不到 bid/ask 标记，所以 delta 在数据上不存在，CLV 只是"收盘在当日区间的位置"，与主动买卖净额无因果关系；② **价位精度**——吸收发生在具体某个价位，日线连价位都不可知，"近似成交量分布"把整日成交压到 (H+L+C)/3 一个点上；③ **量级与档位**——失衡阈值（300%）是相对"单档显示量"定义的，日线没有档；④ **挂单 vs 成交**——冰山、spoofing 需要委托明细，日线只有成交总量，两者在日线上完全不可分。

**反例与失效条件**
- delta 背离可连续出现 3~5 次才反转，把单次背离当反向信号=接飞刀（这是订单流实盘最常见的爆仓原因）。
- 300% 失衡阈值不可跨品种移植：流动性薄的标的上满屏假失衡。
- 涨跌停板上的巨额挂单是**排队**，不是失衡；T+1 使当日买入无法卖出，"吸收"叙事在 A 股要打折。
- 日线代理的硬伤：**CLV 高 ≠ 主动买占优**。一根缩量小阳线可以有 CLV=1.0；一根放量长下影阴线 CLV 可以只有 0.3 但真实存在大量被动接盘。代理与真订单流的相关性我判断为**中低**（不确定，需分钟数据才能实测）。
- 一字板 H=L=C 会让 CLV 除零，必须单独分支，且此类 bar 的一切振幅类代理全部失效。

**冲突点（与批次一）**
- 与威科夫"努力与结果"同源不同层：威科夫用日线总量判"努力无结果"，订单流用逐笔方向判"谁在吸收"。冲突点在**方向归因**。处理：`volume_price` 的努力无结果标签保留，但改名 `absorption_suspect` 并带 `proxy=true`，**不输出"资金流入/流出"这类结论**。
- 与量价四象限：象限说"价升量增=需求跟进"，订单流框架下同样现象可能是"卖方在高位被动派发"。两者不可调和 → 象限降为状态描述（与 batch1 校准结论一致：结构标签不能当方向用）。
- 与蜡烛图：长下影在 Nison 是"锤子=支撑证据"，在订单流是"下方被动买盘"。几何相同、机制不同 → **保留两个标签，但同一根 bar 合成时只计一次权重**，避免重复投票。

**引擎落地建议（函数级）**
```
orderflow_proxy(bars, atr_n=14, vol_n=20) -> dict
  in : OHLCV 日线（统一复权口径）
  out: {clv, clv_ma5, vol_ratio, amp_pct, amp_atr, gap_atr,
        upper_wick_ratio, lower_wick_ratio,
        absorption_suspect: bool, absorption_dir: "unknown",
        proxy_only: True, proxy_confidence: "low"}

volume_profile_daily(bars, lookback=60, bin_atr=0.5) -> dict
  out: {bins:[{px_lo,px_hi,vol}], poc, va_low, va_high, in_va,
        approximation:"volume-at-typical-price",
        error_note:"单日内部价格分布被压成一个点，POC 会向当日典型价聚集"}

footprint(...) -> {"available": False, "reason": "need tick/1m + bid-ask aggressor flag"}
```
下游只允许把 `absorption_suspect`、`gap_atr` 当**条件**（给已有信号加权/降权），**禁止**单独出方向。

**数据可行性**：现有 = 日线 kline_daily（275 万行，raw/复权两套）+ 238 只 qfq CSV，**无分钟线、无 tick、无逐笔**。
→ 表 A 全部 9 条：**需逐笔/分钟数据，当前不可落地**（含 delta、CVD、失衡、吸收、冰山、POC/VA、exhaustion、VWAP 偏离）。
→ 表 B 8 条可在日线落地，但其中"近似成交量分布"只能算**低置信度示意**，不可进评分。
→ 若将来补 1 分钟线，可落地 delta/CVD/日内 VWAP/粗略 POC；补逐笔成交+委托明细才谈得上 footprint 与冰山。

## 三角洲理论：隐藏在市场中的秩序（Delta Phenomenon）

**核心命题**：市场在**时间**维度上存在固定秩序——转折点以稳定的间隔循环出现，可按固定编号（Delta 序列）
预测下一个转折**落在哪几天**。它明确只给**时间**，不给方向、不给幅度；且承认序列会"翻转"（inversion），
顺序颠倒即视为结构切换。**它与批次一所有书的分歧**：艾略特、缠论用结构定义转折，Delta 只看时间不看结构。
我对其具体天数序列的记忆**不确定**，本文不引用任何"书中给的周期天数"。

### 判据表

| 判据 | 计算定义（含阈值/单位） | 方向 | 置信度 |
|---|---|---|---|
| 摆动点提取 | 分型 k=2（左右各 2 根确认）+ 幅度过滤 ≥0.5×ATR14，顶底交替 | 转折点集合，是全部下游的原料 | 高 |
| 间隔样本 | 相邻摆动点之间的交易日差（自然日与交易日须统一，本引擎统一用交易日） | 周期估计的观测值 | 高 |
| 周期稳定性 CV | CV = std(间隔)/mean(间隔)；同一 T 簇内计算 | CV<0.35 视为"准周期"；>0.6 视为无周期 | 中 |
| 周期显著性 | 间隔直方图峰值桶样本数 ≥5，且 峰值/均匀期望 ≥2 | 排除偶然堆积 | 中 |
| 窗口投影 | 从最近已确认摆动点 (d0, type) 起：d0 + n×T ± tol，tol=ceil(0.15×T) 且 ≥1 交易日 | 窗口内预期出现与 d0 **相反**类型的摆动点 | 中 |
| 命中率评估 | hit_rate = hits / windows | 越高越可用 | 高（评估方法本身确定） |
| 随机基线（自建口径） | p0 = 1 − exp(−w / mean_interval)，w=窗口宽（交易日）；lift = hit_rate / p0 | **lift 才是结论**，命中率 70% 可能低于随机 | 高（这是评估口径，非书中内容） |
| 严格样本外 | walk-forward：只用 d<t 的数据估 T，预测 t 之后，滚动推进 | 必须 oos，禁止全样本调参后回看 | 高 |
| 翻转检测 | 同一 T 连续 2 次预测类型与实际相反 | 结构切换 → 停用该 T | 中 |
| 多重比较校正 | p_adj = min(1, p × m)，m = 试过的 T 个数 × 股票数 | 不校正必然"发现"周期 | 高 |

**反例与失效条件**
- **过拟合是结构性缺陷，不是操作失误**：T 自由（3~60 交易日 = 58 个候选）、k 自由、tol 自由 → 数百种组合，
  纯噪声序列也能凑出 lift>1.5。没有 walk-forward + 多重比较校正，这套东西**必然"有效"且必然亏钱**。
- 摆动点越密，宽窗口的随机命中率越高 → 表观命中率虚高（这就是为什么必须先算 p0）。
- **A 股单股历史通常 < 1000 交易日（≈4 年）**：一个 4 年周期只能观察 1 个间隔，统计上不可估。
  记忆中的长周期（季度/年/多年级）在本项目数据上**不可落地**。
- 制度断点（涨跌停、T+1、注册制、退市新规）使早期样本不可比 → 不按制度分段，测出的"周期"是制度的产物。
- 单边趋势市摆动点骤减，周期估不出；震荡市摆动点密集，真周期被噪音淹没——两头都失效。
- 即使时间预测正确，**方向错了照样亏**，所以它单独没有任何交易价值。

**冲突点**
- 与艾略特/缠论：同一天可能"结构未完成但 Delta 窗口已到"。处理：**结构优先、时间让步**——Delta 窗口只允许
  **降低仓位/推迟开仓**，不允许反向开仓；两套字段并存，合成时不加总。
- 与 Brooks（batch1）：Brooks 认为时间不可预测、只跟随价格与信号棒，与本书**直接冲突**。处理：
  Delta 归入"风险闸门"而非"信号源"，不参与 score，代码路径与 `price_action` 隔离。
- 与量价/威科夫：无实质冲突（不同维度）。

**引擎落地建议（函数级）**
```
swing_points(bars, k=2, atr_min=0.5) -> [{idx, date, px, type:"H"|"L"}]

period_scan(swings, T_range=(3,60), tol_ratio=0.15, min_obs=8) ->
  [{T, n_obs, cv, peak_ratio, hit_rate, baseline_p0, lift, p_value, p_adj}]
  # verdict 规则：lift ≥ 1.3 且 p_adj < 0.1 且 cv < 0.35 且 n_obs ≥ 8，否则 "no_edge"

delta_windows(swings, T, horizon=60, tol_ratio=0.15) ->
  [{start_date, end_date, expected:"H"|"L", from_date}]

delta_eval(code, bars, walk_forward=True) ->
  {periods:[...], windows:[...], oos_hit_rate, oos_lift, searched_m, verdict}
```
输出**必须**带 `n_obs` / `oos` / `searched_m`，否则结论不可审计。`verdict` 为 `no_edge` 时下游必须无视。

**数据可行性**：这套东西**原生就在日线**，不需要分钟数据——这是三本书里数据最友好的。
真正限制是**历史长度**：3~30 日周期可做（每只股票 ≥ 数十个间隔）；60 日以上勉强；季度/年/多年级不可做。
可落地的替代路径：把长周期改在**指数**上做（上证/沪深300，历史远长于个股），个股只做短周期。

## 证券市场技术指标百科全书

**核心命题**：指标是把价格/成交量做数学变换后的**度量工具**，不是预测工具。不同指标测的是不同维度，
同维度内的指标高度共线——把 RSI+KDJ+CCI+BIAS 当四票投，等于把"位置"这一维计了四票，制造"共振"的假精度。
正确用法：**一维一代表 + ATR 作统一标尺**（把阈值从"元"变成"ATR 倍数"，才能跨股票比较）。

### 可判定判据表（只挑有独立信息维度的）

| 判据 | 计算定义（含阈值/单位） | 方向 | 置信度 |
|---|---|---|---|
| 趋势方向 · EMA20 斜率 | (EMA20_t − EMA20_{t−5}) / ATR14，单位：ATR/5交易日 | >+0.3 上升；<−0.3 下降；之间=震荡 | 高 |
| 趋势确认 · MACD 柱 | hist=(DIF−DEA)/ATR14，参数**写死 12/26/9** | 与 EMA 斜率同号=可信；背离=衰竭 | 高（公式）／中（阈值） |
| 趋势强度 · ADX14 | TR/(+DM/−DM)→平滑14→DI±→DX=\|DI+−DI−\|/(DI++DI−)×100→ADX=DX 平滑14 | >25 趋势市；<20 震荡市（**决定用哪套策略**） | 高 |
| 波动水平 · ATR14 | TR=max(H−L,\|H−C₁\|,\|L−C₁\|)；输出 atr_pct=ATR/C×100 | 只作**分母**：止损 2×ATR；仓位=风险预算/(2×ATR×价) | 高 |
| 波动位置 · BOLL %B(20,2) | %B=(C−下轨)/(上轨−下轨)，σ 用 20 日总体标准差 | <0 破下轨；>1 破上轨；0.1/0.9 为带内分位 | 高 |
| 波动压缩 · 带宽分位 | width=(上−下)/中；取近 120 日分位 | 分位<20%=压缩，之后扩张概率上升（**方向不定**） | 中 |
| 超买超卖 · RSI14 | Wilder RSI；A 股建议 80/20（70/30 在趋势中长钝化） | 只在 ADX<20 时用；趋势中禁用 | 中 |
| 情绪极端 · KDJ 的 J | RSV=(C−L9)/(H9−L9)×100；K=⅔K₁+⅓RSV；D 同；J=3K−2D | **仅** J>100 / J<0 作极端标记，不给方向 | 中（J 无界、噪音大） |
| 偏离 · CCI20 | (TP−MA20(TP))/(0.015×平均绝对偏差)，TP=(H+L+C)/3 | ±100 常规带，±200 极值 | **低**（与 RSI/BIAS 共线，只作边缘确认） |
| 量能 · OBV 20 日斜率 | OBV_t=OBV_{t−1}+sign(C_t−C_{t−1})×V_t；取 (OBV_t−OBV_{t−20})/mean(V,20) | 与价同向=确认；背离=派发/吸筹 | 中 |
| 量能强度 · 量比 / 换手 | 量比=V_t/mean(V,20)（只能纵向比）；换手=V_t/流通股本×100（可横向比） | 量比>1.5 放量；换手分层：小盘>8%、中盘>5%、大盘>3% | 高（定义）／中（阈值） |
| 相对位置 · 52 周分位 | pos=(C−L252)/(H252−L252) | <0.2 低位区；>0.8 高位区（跨股可比，轮动筛选用） | 高 |

| 量能 | OBV、A/D、MFI、量比、换手 | 中（口径差异大） | OBV 斜率 + 换手（量比留作事件检测） |

→ 13 个指标砍成 **6 票**：趋势方向 / 趋势强度 / 波动 / 位置 / 量能 / 相对位置。

**反例与失效条件**
- RSI 钝化：强趋势中可连续 30+ 日 >70，按超买反手=连续亏损，故必须加 ADX 闸门。
- ADX 滞后：由平滑 DX 得来，趋势走完一半才 >25，**只能定市态，不能当入场信号**。
- OBV 单日污染：一根 10 倍量棒永久改变 OBV 水平 → 只用斜率并用量能归一；更稳的是"价量 20 日相关性"。
- BOLL 低波动压缩后假突破频繁（压缩≠必然扩张，只是概率上升）。
- 换手率若用**总股本**而非**自由流通股本**，会把大股东锁仓算进分母 → 系统性低估换手，阈值全部作废。
- **复权口径是本批最大的工程坑**：ATR / BOLL / 缺口必须用同一复权序列。若 kline_daily 是 raw（不复权），
  除权日假跳空会把 ATR 抬高、把带宽顶开，所有以 ATR 为单位的阈值集体失效。落地前必须先确认口径。
- 所有指标都是价格的滞后函数，**不产生领先信息**；共线指标的"共振"是假精度。

**冲突点**
- 与 Brooks（batch1）：Brooks 认为指标是价格的重新包装。采纳其精神——指标只做**度量与状态判定**
  （ATR 作标尺、ADX 定市态、%B 定位置），**不作方向信号源**。与 batch1 回测结论（结构标签不能当方向）一致。
- 与缠论：batch1 用 MACD **面积**判背驰。面积对参数极度敏感 → 必须锁定 12/26/9 并把单位归一为 ATR，
  否则不同股票的"面积"不可比。这是硬约束，写进代码注释。
- 与威科夫/量价：OBV 用收盘方向二分（+V/−V），威科夫的"努力"看整根棒的量与位置 → 口径不同。
  保留两套，OBV 只做长周期量能趋势确认。
- 与订单流：OBV / 量比**不可替代** delta / CVD。禁止把 OBV 当 delta 用（这是最容易犯的越界）。

**引擎落地建议（函数级）**
```
indicator_pack(bars, params={ema:20, macd:(12,26,9), adx:14, atr:14, bb:(20,2), rsi:14, cci:20}) -> dict
  out: {ema20_slope_atr, macd_hist_atr, adx14, di_diff, atr14, atr_pct,
        bb_pctb, bb_width_pctile, rsi14, kdj_j, cci20,
        obv_slope20, vol_ratio, turnover_pct, pos52w,
        cluster_of: {字段→簇名}}

cluster_conviction(pack) -> {trend_dir, trend_strength, volatility, position, volume, rel_pos}
  # 每簇 ∈ [-1,1]，每簇只由代表指标贡献一票
  # 附 redundancy_removed: [被丢弃的共线指标]，便于审计
```

**数据可行性**：全部只需 OHLCV → **日线完全可落地**，且不需要分钟数据。
两个约束：① 换手率需流通股本/自由流通股本，本项目是否有该字段**我不确定**，若无则只能用"成交额/总市值"
近似（误差：无法反映解禁与流通比例变化）；② financial_summary 仅 216 行 → 任何财务加权类指标（PEG、ROE 加权）
**不可落地**，不要在设计里留钩子。

## 落地优先级

### A 档 · 能立刻接进日线引擎（数据已在手，置信度够）
1. `orderflow_proxy()`：CLV、CLV 5 日均、量比、振幅/ATR、缺口/ATR、上下影占比 —— 低置信度代理，只作条件。
2. `volume_profile_daily()`：日线近似成交量分布（POC/VA），**仅展示，不进评分**（失真大）。
3. `swing_points()` + `period_scan()` + `delta_windows()`：Delta 短周期（T ∈ 3~30 交易日）、walk-forward、带 lift 与 p_adj。
4. `indicator_pack()`：EMA20 斜率、MACD 柱（ATR 归一）、ADX14、ATR14、BOLL %B、带宽分位、RSI14、OBV 斜率、量比、52 周分位。
5. `cluster_conviction()`：6 簇投票 + `redundancy_removed` 审计，替换现有"多指标共振"加权。
6. ATR 作为全引擎统一分母（止损 2×ATR、阈值改 ATR 倍数）——这一条收益最大、风险最小。

### B 档 · 需补数据才能做
1. delta / CVD / 主动买卖分解 —— 需分钟线 + bid-ask 标记（1 分钟够用，逐笔更好）。
2. footprint、堆叠失衡、对角失衡 —— 需逐笔成交明细；失衡阈值还需按 A 股分市值校准。
3. 吸收（absorption）的**价位**定位 —— 需分钟或逐笔，日线只能给"嫌疑"布尔值。
4. 冰山单识别 —— 需委托明细（Level-2 逐笔委托），免费数据基本拿不到。
5. 真实 POC / Value Area —— 需分钟级价格分布；日线近似误差不可控。
6. Delta 长周期（季度/年级）—— 个股历史不足；建议改在指数上做，或等更长历史入库。
7. 换手率分层阈值 —— 需自由流通股本字段（当前有无不确定）。

### C 档 · 不建议做（做了会害事）
1. 用日线伪造 footprint / 用 CLV 冒充 delta —— 会产出一条看起来专业、实际无信息的字段。
2. Delta 长期周期序列直接抄用"书中的天数" —— 我的记忆不确定，且必然过拟合；只允许数据自己长出来。
3. 把 Delta 窗口当方向信号 —— 它只给时间，方向必须由结构模块给。
4. KDJ 方向、CCI 方向、MFI（RSI+量比冗余）、ROC 独立投票 —— 与已有指标共线，纯重复投票。
5. 多指标共振加权（MACD+KDJ+RSI+CCI 各一票）—— 假精度，已被 batch1 回测证伪同类型做法。
6. 任何"资金流入/流出"结论由日线量价推出 —— 缺 bid/ask 归因，方向不可知。

> 三本书的诚实结论：《订单流交易》在本项目**基本不可落地**（只有 8 个降级代理），
> 《三角洲理论》**可落地但最可能是过拟合**（必须 walk-forward，且大概率 verdict=no_edge），
> 《指标百科全书》**最实用但也最容易误用**（价值全在"去共线 + ATR 归一"，不在指标本身）。
