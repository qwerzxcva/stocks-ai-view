## 1. 日本蜡烛图技术（Steve Nison）

**核心命题**：单根/组合 K 线的实体与影线比例记录了当日多空推进与抵抗的过程；
但**形态本身不产生信号，位置才产生信号**——同一根锤子线在下跌末端是支撑证据，
在上涨中段只是中继。这是全书最容易被读者忽略、也最决定成败的一句。

**判据**
- 锤子/上吊：下影 ≥ 2×实体，实体位于区间上 1/3，上影 ≤ 0.5×实体，且全幅 ≥ 0.8×ATR
- 射击之星/倒锤：镜像；出现在摆动高点附近才算反转证据
- 吞没：后一根实体完全包住前一根实体且方向相反，实体放大 → 反转力度
- 孕线：前一根实体 > 1.2×ATR 且被完全包孕 → 趋势暂歇（预警，不是反转）
- 十字星：实体/全幅 ≤ 0.1 → 多空均衡，只在长趋势末端有意义
- 启明星/黄昏星：长实体 → 小实体 → 反向长实体收过第一根中点
- 持续形态（三法、跳空并列阴阳线）在趋势中继处用，方向与主趋势一致

**位置条件（Nison 的真正内核）**：形态出现的相对位置由「距最近摆动点 < 0.5×ATR」判定，
这是把"教科书图例"变成可执行代码的关键。

**失效与冲突**
- 日线以下级别噪音大，同一形态成功率显著下降 → 本引擎只在日线用
- 与 Al Brooks 冲突处：Brooks 认为单根反转棒信息量很低，信号棒须配"后续跟随"才成立。
  处理方式：**保留两套**——`candle_patterns` 给形态标签，`price_action` 要求 follow-through，
  合成评分时形态权重低于结构权重（12 分/档 vs 40 分/档）
- A 股涨跌停制度会让吞没/星线在连板股上失真 → 连板场景应由涨跌停模块覆盖，不交给蜡烛模块

**代码**：`candle_patterns()`；权重 12×strength
**置信度**：高（形态定义）；中（0.8×ATR 的全幅门槛是回测待调项）

## 2. 高级趋势技术分析（Al Brooks）

**核心命题**：市场只有两种状态——趋势与区间，且**80% 的时间在区间**。趋势的微观结构是
"尖峰（spike）+ 通道（channel）"：一段急速位移（尖峰）之后转入斜率变缓的通道，
通道内出现连续 1~3 根逆势棒即为回撤买点（High 1 / Low 1 / Low 2）。

**判据**
- 趋势三态：摆动高点与低点同时抬高 = 上升结构（HH+HL）；同时降低 = 下降结构；不一致 = 区间
- 趋势棒：实体 ≥ 0.6×全幅；十字棒 ≤ 0.25；反转棒 = 破前极值但收回且实体 ≥ 0.5
- 缺口棒 / 均线缺口棒：连续趋势棒远离 20EMA 后首次回踩 → 高胜率入场点
- 测量移动：尖峰起点到尖峰终点的距离，从通道起点上投，作为最小目标
- 趋势强弱：连续趋势棒根数、回撤是否触及 20EMA、通道上下轨触碰次数

**失效与冲突**
- Brooks 反复强调"任何信号都可能失败"，所以入场必须带"信号棒高低点"作为止损位；
  这一点与《专业投机原理》的止损前置同向，可合并到交易管理层
- 与缠论冲突：Brooks 的"趋势"是视觉斜率与棒序，缠论的"趋势"要求至少两个同向中枢。
  处理：两套并存，`trend`（棒序口径）与 `chan.last_bi_dir`（笔口径）分别输出，不强行统一

**代码**：`price_action()` 的 trend/bar_type/measured_move 部分
**置信度**：高

## 3. 高级波段技术分析（Al Brooks）

**核心命题**：区间不是"没方向"，区间是**突破模式（breakout mode）**——上下边界各挂着一批
止损单，谁先被触发谁提供燃料。区间内的正确动作是"低买高卖赚小钱或被止损"，
真正的钱在**区间突破后的第一次回抽**。

**判据**
- 区间判定：近 20 根振幅/中位价 < 6%（窄幅）或 < 12%（宽幅）
- 突破模式：区间内部出现多次对边界的假突破（failed breakout）→ 真突破临近
- 失败突破是最强反向信号：突破后 3 根内收回 → 反向做，止损放在假突破极值外
- 二次信号（second signal）：同一位置第二次出现的形态，胜率显著高于第一次
- 区间内禁忌：不追、不在区间中部开仓、不在第三次触边时仍假设区间有效

**与第 1、2 本的互补（同一现象多角度，不删）**
- 蜡烛图把"高位长上影"叫上影线/射击之星；Brooks 把它叫"强突破失败后的反转棒"；
  威科夫把它叫"上冲回落（UT）"。三者判据几何上重叠、语义不同 → 引擎里保留三个标签，
  合成评分时才合并，这样输出能回溯到具体方法论

**代码**：`price_action()` 的 failed_breakout / RANGE_BAND 分支
**置信度**：高

## 4. 高级反转技术分析（Al Brooks）

**核心命题**：反转不是一根棒，是一个**过程**：极值（climax）→ 反向突破趋势线 →
回抽测试 → 二次入场。多数"反转信号"失败，是因为交易者把过程的第一阶段当成了结论。

**判据**
- 主要趋势反转（MTR）四要件：① 趋势末端出现加速/衰竭；② 反向突破趋势通道线；
  ③ 回抽不创新极值；④ 出现次级信号（双顶/双底、楔形三推、最终旗形）
- 双顶/双底：两次极值差 < 0.5×ATR 且第二次量能衰减 → 成立度提高
- 楔形三推：三次递进极值 + 推力递减 → 反转概率高
- 最终旗形：趋势末端的浅幅整理，突破方向多为反向
- 失败信号的用法：反转信号失败后，原趋势往往加速（"失败的反转是趋势的燃料"）

**代码**：由 `price_action` 的 failed_breakout + `candle_patterns` 的位置条件联合近似；
完整的 MTR 四要件状态机尚未实现（见「待补」）
**置信度**：中（四要件状态机是下一步；当前只覆盖 ②③ 的几何部分）
**待补**：`mtr_state_machine()` — 记录"极值→破线→回抽→二次信号"的状态迁移

## 5. 零基础看懂缠论

**核心命题**：走势是**级别自相似**的。把 K 线做包含关系处理后，得到分型；分型连成笔；
笔连成线段；三段以上重叠构成中枢；中枢的延伸、新生、扩张决定走势类型；
**走势终完美**——任何走势类型必然完成，未完成的结构不能作为交易依据。

**判据（可直接编码的部分）**
1. 包含关系处理：相邻两根一根完全包含另一根时合并；向上处理取"高高、低高"，向下取"低低、高低"
2. 分型：合并后的三根中，中间一根高点最高=顶分型，低点最低=底分型
3. 笔：顶底交替 + 两分型之间至少间隔 4 根合并 K 线 + 价差超过一档
4. 中枢：连续三笔的重叠区间，ZG=min(三笔高点)，ZD=max(三笔低点)；ZG>ZD 才成立
5. 三类买点：
   - 一买：下跌趋势中最后一段中枢离开后出现背驰（本级别趋势结束）
   - 二买：一买后第一次回抽不破前低
   - 三买：上破中枢后回抽**不回中枢区间内**（ZD 之上站稳）
   - 三卖镜像
6. 背驰：同向两段比较力度（价格幅度/成交量/MACD 面积），后段更弱 → 背驰
7. 级别：日线笔 ≈ 30 分钟线段，需分钟数据才能做多级别联立（本引擎暂只做日线级别）

**失效与冲突**
- 缠论严格意义的"笔"要求分型区间不重叠且满足特征序列，工程实现普遍简化 →
  本引擎是**简化版**，输出里必须带 `bi_count` 让人知道结构是否可靠（笔太少=结构未成型）
- 与 Brooks 冲突：缠论用"中枢"定义震荡，Brooks 用"区间"；两者判定阈值不同，不可混用
- 与波浪冲突：都做"级别+结构"，但缠论允许中枢延伸，波浪要求浪型不重叠 → 双标签输出

**代码**：`chan_theory()`
**置信度**：中（分型/笔/中枢骨架可靠；一买/二买需分钟级别与 MACD 面积，当前只有三买/三卖是纯几何判定）

## 6. 艾略特波浪理论

**核心命题**：群体情绪以 5 浪推动 + 3 浪调整的固定节奏展开，且受三条**硬规则**约束——
违反任意一条，浪型计数即作废。数浪的价值不在预测，而在给出**失效位**。

**硬规则**
1. 浪 2 不能跌破浪 1 起点（推动浪）
2. 浪 3 不能是最短的推动浪
3. 浪 4 不能进入浪 1 的价格区间（非对角线情形）

**常用指引（非硬规则，只作打分）**
- 浪 2 回撤 0.382~0.618；浪 4 回撤 0.236~0.5
- 浪 3 常为浪 1 的 1.618 倍；浪 5 常等于浪 1
- 交替原则：2 浪简单则 4 浪复杂（横盘/三角形）
- 调整浪形态：锯齿（5-3-5）、平台（3-3-5）、三角形（3-3-3-3-3）

**工程现实（必须说清）**：自动数浪是伪命题——同一段走势可有多种合法计数。
本引擎只做**候选识别 + 失效位**，`confidence` 上限 0.8，且绝不单独作为入场依据；
它的正确用法是给已有信号提供"位置背景"（例如三买出现在浪 4 末端时权重上调）。

**代码**：`elliott()`（摆动序列上的 5 浪启发式 + 三规则校验）
**置信度**：中（规则可靠，但摆动点参数 k=2 对浪型敏感，换 k 会改变计数 → 输出必须带 k 值）

## 7. 量价操盘法

**核心命题**：价格是结果，成交量是原因。量价关系分四象限，每种组合对应不同的资金意图，
而**量能的相对水平（量比/换手）比绝对量更重要**。

**判据**
- 量比 = 当日量 / 20 日均量
- 四象限：价升量增（需求跟进，健康）／价升量减（无量上涨，持续性差）／
  价跌量增（供给涌出，危险）／价跌量减（抛压衰减，可能筑底）
- 地量地价：连续 20 日量能萎缩至 60% 以下 + 价格横盘 → 底部区域特征
- 天量天价：历史量能 2 倍以上 + 长上影 → 顶部区域特征
- 量堆：连续 3 根以上量比 > 1.5 且价格重心上移 → 资金持续介入
- 换手率区间：< 1% 无人问津；3~8% 活跃；> 15% 多为博弈盘（A 股口径）

**失效与冲突**
- 与威科夫重叠：都讲"努力与结果"，但威科夫给的是**阶段序列**，量价法给的是**单日象限** →
  两者都保留，短周期用象限，中周期用阶段
- A 股量能受 T+1 与涨跌停影响，量比阈值 1.2 需按市值分层校准（小盘股常态量比偏高）

**代码**：`volume_price()` 的 vr / quadrant 部分
**置信度**：中

## 8. 威科夫操盘法

**核心命题**：价格由"综合人"（主力）在四个阶段间循环推动：吸筹 → 拉升 → 派发 → 下跌。
识别阶段不靠猜，靠**事件序列**：吸筹区必须依次出现 PS（初步支撑）、SC（抛售高潮）、
AR（自动反弹）、ST（二次测试）、Spring（弹簧/假破）、Test、SOS（强势信号）、LPS（最后支撑点）。

**三大定律**
1. 供需定律：需求 > 供给则涨
2. 因果定律：横盘区间（因）的宽度决定后续行情（果）的高度 → 用点数图测算目标
3. 努力与结果定律：成交量（努力）与价格位移（结果）背离 → 趋势将变

**判据（本引擎已落地）**
- 无需求（no demand）：上涨棒但量能低于前两根，收盘居中 → 需求缺失
- 上冲回落（UT/UTAD）：创近 10 根新高但收在下 1/3 且放量 → 派发
- 停止量（stopping volume）：放量下跌但收盘远离最低 → 有人接货
- 努力无结果：量比 ≥ 1.8 但涨跌幅 < 0.5% 且全幅 < 1.2×ATR → 吸筹/派发待定
- 阶段提示：30 根区间内（振幅 < 12%）量能收敛 + 价格抬向上沿 = 吸筹；
  量能放大 + 价格下移 = 派发；突破区间 = 拉升/下跌

**待补**：完整事件序列状态机（PS→SC→AR→ST→Spring→SOS→LPS）与点数图目标测算
**代码**：`volume_price()` 的 events / phase 部分
**置信度**：中（事件几何判据可靠；阶段命名易过度解读 → 输出用 `phase` 提示而非结论）

## 工程上踩到的两个真 bug（已修，均有测试锁住）

1. **位置条件永不命中**：`swings()` 的分型需左右各 k 根确认，因此**最后一根 K 线永远不是摆动点**。
   早期版本只用摆动点判「是否处于低位」，导致「刚创新低的那根锤子线」永远检不出来——实盘等于形态失效。
   修正：叠加滚动窗口判据（与近 20 根最低/最高距离 ≤ 1 ATR），修正后全市场蜡烛标签从个位数增到二百余个。
2. **校准方向标反**：`_is_bullish_key()` 早期用子串判断，`chan:third_sell` 包含 `chan:third`，
   于是三卖被当成多头标签、edge 标成 trend，方向直接反了。修正为按 ` & ` 切 token 精确比对。
