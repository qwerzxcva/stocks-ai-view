## 二、同主题多手法：分条保留，不合并

同一主题下不同作者的判据**有条件差异**，合并会丢掉前置条件，所以按条保留：

| 主题 | 保留的独立手法 | 分条保留的理由（不合并的原因） |
|---|---|---|
| 反转识别 | #4 反转四要件状态机（极值→破线→回抽→二次信号）；#13 Sperandeo 2B 法则；#8 威科夫 Spring/UT | 三者触发条件不同：#4 要四要件齐；2B 只要「破前高后收回」；Spring 要「跌破后放量拉回」。合成一条会把「失败突破」误记成「bottom_confirmed」 |
| 突破 | #3 区间突破 + 失败突破反向；#27 利弗莫尔关键点；#15 首板 | 时间尺度不同（区间/关键点/涨停），且实测方向相反（`breakout:up` −0.68% vs 首板 +1.40%） |
| 量价 | #7 量比四象限（地量地价/天量天价）；#8 努力与结果背离；#9 delta/CVD | #7 #8 可用日线，#9 要逐笔；代理量只能算 #7 #8，不能冒充 #9 |
| 止损与退出 | #12 幽灵「只持有正确仓位」+ 时间止损；#11 亚当止损前置；#29 打板机械止损；#14 连亏熔断 | 四条作用在不同对象：仓位合法性 / 建仓即止损 / 单票执行 / 账户级熔断。合并会让账户级熔断被单票止损顶掉 |
| 选股框架 | #24 富致中源多维打分；#32 指标共线去重；#23 趋势过滤 | #24 给加权框架，#32 给「先删共线再加权」的约束，#23 给最后一道方向闸 |

## 四、去重落到代码的三条硬规则

1. **方向与权重一律从校准表取，禁止硬编码书本先验**。三个层（结构 / 威科夫 / 题材）在代码里只做**条件器**；
   这条规则 2026-10-30 在端上被执行过一次：书籍票权重从硬编码 `W_BOOK = 0.6` 改为云端规格下发
   （`weights.book`，缺键即停用），见 `skapp-app/docs/ISSUES.md`。
2. **置信度「低」禁止直接进代码**（#10 #24 #25 #31 #33）——低置信项只登记判据，不进引擎。
3. **同名不同义不合并**：题材两套口径同名率仅 3.3%，`mapping_health()` 负责在数据层拦住，
   不靠卡片文字「差不多」糊过去。

## 五、维护

- 新增一本书 → 先在本表判断「是否已有同主题条目」：是则**加一行手法**，不是改原行；否则新增编号。
- 每次 `--calibrate` 后若某标签方向翻转：先改 `../BOOK-LAYERS.md` 实测表，再同步端上
  `BookSignalEngine.CALIB`，最后才动权重。
- 任何新数据接入（L2 / 分钟 / 龙虎榜 / 财务全量 / 宏观序列），先改 `SUMMARY-33.md` 第三节的缺口行，再动引擎。
