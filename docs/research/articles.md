## 3. V2EX t/1229982《开源股票数据库 free-stockdb 快速破 1000 星》（快照）
- URL: https://www.v2ex.com/t/1229982 （直连被拦截；内容来自搜索快照 + 同作者 CSDN 文章 + GitHub README）
- 主题：免费本地 A 股量化数据引擎（不是行情源），GitHub: https://github.com/hello245m/free-stockdb （约 2600 star，MIT；注意核心引擎为闭源二进制/部分 C++、Rust 计算核心）。
- 数据源/接口：数据经 sync_url.txt 配置的同步节点分发（Zstd 压缩、SHA-256 校验、断点续传），支持 file:// 离线快照；文中实测对照了新浪/东财/同花顺/腾讯/雪球的后复权价差异。
- 算法/框架思路：
  - 7 模块：行情源+数据库+缓存+查询 SDK+计算引擎+更新程序；同步层与策略层彻底解耦。
  - 复权：「写时计算」累计因子时间轴（Cumulative Factor Timeline），区别于每日重算 factor，0 额外字段存储。
  - 计算：39 种技术指标 + 5 种指数编制（等权/流通市值加权/成交额加权等）批量计算，zb.get() 带 cross 参数直接输出金叉/死叉信号。
  - 板块：申万一二三级 + 1200 概念板块双向映射 bk.get()。
  - 接口：Python SDK / HTTP / Excel-WPS / HTML / MCP 五种调用。
- 增量价值：本地数据底座架构与复权算法是重要参考；其 sync 节点本身也是一个现成的全市场日K/分钟K/ETF 数据来源（7400+ 只，2000 年至今），但依赖作者分发的数据，合规与可持续性需评估。

## 4. V2EX t/1197162《分享完全免费的 A 股数据获取库 finshare》（快照）
- URL: https://www.v2ex.com/t/1197162 （直连被拦截；内容来自搜索快照 + 官方文档 finvfamily.github.io/finshare）
- 主题：免费 Python 数据库 finshare，GitHub: https://github.com/finvfamily/finshare ，pip install finshare，无需 API Key。
- 数据源/接口：东方财富（主力，含财务/龙虎榜/融资融券）、腾讯财经、新浪财经（仅快照）、通达信（需本地客户端）、BaoStock、Yahoo Finance（美股）、天天基金（基金净值）。接口：历史 K 线（qfq）、实时快照、批量快照、资金流向、龙虎榜、利润表、基金/期货/证券列表。
- 算法/框架思路：DataSourceManager 多源自动故障切换；熔断器、智能路由、健康探测、状态统计；MemoryCache/RedisCache；AsyncDataSourceManager 异步批量；统一返回格式。与 akshare 对比：胜在工程稳定性层而非接口数量。
- 增量价值：底层源与注册表重合度高；可直接借鉴的是多源故障切换/熔断/缓存/异步编排的工程实现。

## 汇总：增量线索优先级
1. pytdx/mootdx 通达信 TCP 协议源 + DuckDB 本地增量管道（文章 5）——数据源与架构双增量。
2. free-stockdb 的「写时计算」复权因子时间轴与 39 指标批量计算设计（文章 3）——自研引擎链可直接对照。
